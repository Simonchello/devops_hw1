# ДЗ №1 — Фундамент DevOps-инфраструктуры

Примак Семён Алексеевич, группа Б13-404.

Настройка Ubuntu через Ansible, отдельный nginx через Terraform,
окружение Docker Compose и мониторинг через Bash.

## Структура проекта

- `ansible/` — настройка выданной Ubuntu VM.
- `terraform/` — nginx, отдельная Docker-сеть и том.
- `scripts/` — мониторинг сервисов.
- `compose/` — reverse proxy и приложение Hello World.
- `docs/screenshots/` — скриншоты результатов для сдачи.

## Порядок выполнения

Согласно уточнению преподавателя от 12 октября 2026 года, этап 2
исходного задания заменён работой с провайдером `kreuzwerker/docker`.
Сначала Ansible настраивает предоставленную VM, затем Terraform
создаёт отдельный nginx с томом в явно заданной сети и публикует его
на нестандартном HTTP-порту. Окружение Compose работает в своей сети.
